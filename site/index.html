Seus agentes de código rodam nas máquinas fortes. Você abre de qualquer uma. Your coding agents run on the strong machines. You open them from any one.

O casca abre shells e agentes (claude, codex, devin…) nos seus outros hosts, por ssh + tmux. Ele só transporta o terminal: o agente roda lá, dentro de tmux. Fechar a janela ou perder a rede não mata nada. casca opens shells and agents (claude, codex, devin…) on your other hosts, over ssh + tmux. It only carries the terminal: the agent runs over there, inside tmux. Closing the window or losing the network kills nothing.

Go 1.22+

$ git clone https://github.com/jazzautomations/casca && cd casca
$ go build -o casca . && ./casca init
$ ./casca tui

Ainda não há binários prontos para baixar. A janela nativa (gui/casca-gui) pede python3-gi, gir1.2-gtk-3.0 e gir1.2-vte-2.91.There are no prebuilt binaries yet. The native window (gui/casca-gui) needs python3-gi, gir1.2-gtk-3.0 and gir1.2-vte-2.91.

compila numa máquina, roda na outrabuild on one machine, run on the other

$ CGO_ENABLED=0 GOOS=linux GOARCH=386 go build -trimpath -ldflags="-s -w" -o casca .
$ ./deploy/install.sh root@HOST USUARIO

O install.sh copia o binário e a janela, e cria um serviço runit (testado em antiX).install.sh copies the binary and the window, and creates a runit service (tested on antiX).

01 · por quêwhy

O notebook velho não roda o agente. Mas roda um terminal.The old laptop can't run the agent. It can run a terminal.

O casca nasceu no mesmo Dell Latitude D610 do jazz-cli: Pentium M de 32 bits, 2 GB de RAM e um WiFi que cai por minutos. Claude Code, Codex e Devin não rodam ali, mas rodam nas outras máquinas da rede.

casca was born on the same Dell Latitude D610 as jazz-cli: a 32-bit Pentium M, 2 GB of RAM and WiFi that drops for minutes. Claude Code, Codex and Devin don't run there, but they run on the other machines on the network.

A ideia veio do Termius (hosts salvos, um toque para conectar) e do Orca (ver de relance o que cada agente está fazendo). Nenhum dos dois roda em Linux de 32 bits. O casca faz o pedaço que importa aqui e nada além: escolher o host, abrir o agente, não perder a sessão.

The idea came from Termius (saved hosts, one tap to connect) and Orca (seeing at a glance what each agent is doing). Neither runs on 32-bit Linux. casca does the part that matters here and nothing more: pick the host, open the agent, don't lose the session.

Não é um substituto de nenhum dos dois. Não tem transferência de arquivos, cofre de chaves nem sincronização; usa o ssh e as chaves que a máquina já tem.

It replaces neither. There is no file transfer, key vault or sync; it uses the ssh and the keys the machine already has.

02 · o que ele fazwhat it does

Três interfaces, o mesmo motor.Three interfaces, one engine.

Janela nativa, menu no terminal ou navegador. As três rodam o mesmo binário e a mesma reconexão.Native window, terminal menu or browser. All three run the same binary and the same reconnection.

  • Tudo que está vivo, na lateralEverything alive, in the sidebar

    Um cartão por host e, embaixo, as sessões tmux que existem lá, abertas nesta janela ou não, com o comando em primeiro plano e há quanto tempo saiu texto. Um clique abre.

    One card per host and, under it, the tmux sessions that exist there, open in this window or not, with the foreground command and how long ago it printed. One click opens it.

  • A rede cai, a sessão ficaThe network drops, the session stays

    Quando o ssh morre, o casca reabre com espera de 1, 2, 4, 8 e 15 s, sem desistir, e só reanexa o tmux: nunca relança o agente sozinho. Erro de autenticação não é repetido.

    When ssh dies, casca reopens it with 1, 2, 4, 8 and 15 s waits, never giving up, and only reattaches tmux: it never relaunches the agent by itself. Authentication errors are not retried.

  • Quem está trabalhandoWho is working

    Cada sessão aberta tem um ponto: girando enquanto sai texto, verde quando parou e você ainda não olhou. É uma estimativa pela atividade da tela, não um estado exato do agente.

    Each open session has a dot: spinning while text comes out, green when it stopped and you haven't looked yet. It is an estimate from screen activity, not the agent's exact state.

  • Pelo tecladoFrom the keyboard

    Em "Nova sessão": setas escolhem host e agente, Enter abre. Ou digite servidor claude. user@host conecta num host que ainda não está cadastrado.

    In "New session": arrows pick host and agent, Enter opens. Or type server claude. user@host connects to a host that isn't saved yet.

  • No celular tambémOn the phone too

    casca serve abre uma interface web (xterm.js) com teclas extras para toque. Escuta só em 127.0.0.1 e no IP da tailnet, com token; nunca em 0.0.0.0.

    casca serve opens a web interface (xterm.js) with extra keys for touch. It listens only on 127.0.0.1 and the tailnet IP, with a token; never on 0.0.0.0.

  • Nada novo para confiarNothing new to trust

    Sem conta, sem nuvem, sem cofre próprio. O casca chama o ssh do sistema; chaves e known_hosts continuam onde estavam. No host de destino só precisa existir tmux.

    No account, no cloud, no vault of its own. casca calls the system ssh; keys and known_hosts stay where they were. The target host only needs tmux.

03 · como funcionahow it works

Um ssh, um tmux, e o comando digitado dentro dele.One ssh, one tmux, and the command typed into it.

janela / TUI / navegador ──> casca ──ssh -tt──> host: tmux new-or-attach c-<agente>

Numa sessão nova, o casca cria o tmux com o shell normal do usuário e digita o comando do agente. Assim o agente pega o mesmo PATH que você teria na mão, e sair dele deixa um shell em vez de matar a sessão.

For a new session, casca creates the tmux with the user's normal shell and types the agent command. That way the agent gets the same PATH you'd have by hand, and quitting it leaves a shell instead of killing the session.

Hosts que seguram a conexão até uma pessoa aprovar (como o Tailscale SSH em modo check) mostram o link na aba; o casca espera até 10 minutos e só considera a sessão criada depois que o ssh realmente entra.

Hosts that hold the connection until a person approves (such as Tailscale SSH in check mode) show the link in the tab; casca waits up to 10 minutes and only treats the session as created once ssh actually gets in.

Os estudos que embasaram o desenho estão no repositório: Termius, Orca e trabalhos anteriores.

The studies behind the design are in the repository: Termius, Orca and prior art.

04 · limiteslimits

O que ele ainda não faz.What it doesn't do yet.

É um projeto novo (v0.2), feito para uma máquina. Espere arestas.It is a new project (v0.2), built for one machine. Expect rough edges.

  1. 01

    Estado exato do agenteExact agent state

    Hoje é atividade na tela mais o sino do terminal. O Orca usa hooks nos agentes para saber "trabalhando / pedindo permissão / terminou"; aqui isso ainda não existe.

    Today it is screen activity plus the terminal bell. Orca uses agent hooks to know "working / asking permission / done"; that doesn't exist here yet.

  2. 02

    Binários prontosPrebuilt binaries

    Por enquanto é compilar do código. A janela nativa só foi usada em Linux com GTK3.

    For now you build from source. The native window has only been used on Linux with GTK3.

  3. 03

    Tela dividida e notificaçõesSplit view and notifications

    Uma sessão por aba. Não há painéis lado a lado na janela nativa nem aviso fora da janela quando um agente termina.

    One session per tab. There are no side-by-side panes in the native window and no notification outside it when an agent finishes.

  4. 04

    Arquivos e portasFiles and ports

    Sem SFTP e sem redirecionamento de portas. A interface web envia um arquivo por vez para /tmp do host; é só isso.

    No SFTP and no port forwarding. The web interface uploads one file at a time to the host's /tmp; that is all.
